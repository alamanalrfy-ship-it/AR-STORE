# نظام مؤسسة ميثاق السلامة التجارية

نظام مبيعات ومخزون ومحاسبة — ملف واحد (HTML/CSS/JS)، بلا خادم وبلا قاعدة بيانات خارجية.

## النشر على Vercel
1. ارفع هذا المجلد إلى مستودع جديد على GitHub (خطوات أدناه).
2. في vercel.com اختر **Add New → Project**، ثم اختر هذا المستودع، واضغط **Deploy** بلا أي إعداد إضافي.
3. سيعطيك Vercel رابطًا فوريًا بصيغة `اسم-المشروع.vercel.app`.

## الرفع إلى GitHub
```bash
cd اسم-المجلد
git init
git add .
git commit -m "النسخة الأولى"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

## تنبيه مهم عن البيانات
البيانات (الفواتير والمنتجات والعملاء) تُحفظ داخل متصفح كل جهاز يفتح الرابط، وليست مشتركة بين الأجهزة. لنقل البيانات بين الأجهزة استخدم "نسخ احتياطي واستعادة" داخل صفحة "المستخدمون والنسخ".

## كتالوج معدات السلامة
من صفحة "المنتجات والمخزون" زر "استيراد كتالوج السلامة والإطفاء" يضيف 500 صنف و100 مورد جاهزين (جدة/الرياض/الدمام) دفعة واحدة، بأمان بدون تكرار إن ضُغط أكثر من مرة.

## المستخدمون الافتراضيون
عند أول تشغيل ستجد 5 حسابات جاهزة بكلمات مرور مؤقتة يجب تغييرها فور الدخول.
